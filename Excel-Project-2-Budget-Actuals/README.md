# 💰 Project 2: Budget vs Actuals Dashboard

## 🛠️ Tools Used
Microsoft Excel

## 📋 Project Overview
Built an interactive Budget vs Actuals Dashboard analyzing $1M+ 
in spending across 6 departments and 20 categories for the year 2024.

## 🎯 Problem Statement
A finance team needed visibility into departmental spending vs planned 
budget to identify overspending and cost saving opportunities.

## 🔍 Approach
- Structured budget and actual spend data across 12 months
- Built 3 Pivot Tables for Department, Monthly and Category analysis
- Applied conditional formatting — red = over budget, green = under budget
- Created 3 interactive charts — Bar, Line, Pie
- Added 2 Slicers for Department and Month filtering
- Designed KPI Dashboard with Total Budget, Actual Spend, Variance

## 📈 Key Insights
- IT and HR exceeded budget by 7% and 6% respectively
- Operations and Finance came in under budget
- January had the highest spending at $91,217
- Training was the highest spending category at $107,037
