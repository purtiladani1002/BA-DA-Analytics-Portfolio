# 📊 Project 1: Sales Performance Tracker

## 🛠️ Tools Used
Microsoft Excel

## 📋 Project Overview
Built an interactive Sales Performance Dashboard analyzing 100 sales 
transactions across 4 regions and 5 salespersons for the year 2024.

## 🎯 Problem Statement
A sales team needed a way to track and visualize individual and regional 
performance against targets across 12 months.

## 🔍 Approach
- Structured raw data with 13 columns
- Built 3 Pivot Tables for Region, Salesperson and Monthly analysis
- Created 3 interactive charts — Bar, Column, Line
- Added 2 Slicers for Region and Month filtering
- Designed a clean KPI Dashboard

## 📈 Key Insights
- Diana Patel exceeded her target by the largest margin
- Ethan Brooks was the only underperforming salesperson
- Sales peaked in January and dipped mid-year

## 💡 Skills Demonstrated
- Data organization & structuring
- Excel formulas (IF, TEXT, SUM, COUNTIF)
- Pivot Tables & Pivot Charts
- Interactive Slicers
- Dashboard design
- Business insights & analysis
