# 🗄️ Project 3: Customer Orders Database

## 🛠️ Tools Used
SQL, DB Browser for SQLite

## 📋 Project Overview
Designed and built a complete relational database with 4 tables 
and wrote 15 SQL queries from basic to advanced level.

## 🎯 Problem Statement
A business needed a structured database to track customer orders, 
products, and transactions with the ability to query insights on demand.

## 🗂️ Database Structure
| Table | Records | Description |
|---|---|---|
| Customers | 10 rows | Customer details across Canada |
| Products | 10 rows | Electronics, Fashion, Home products |
| Orders | 10 rows | Orders with payment and shipping info |
| Order_Items | 10 rows | Product line items per order |

## 🔍 15 SQL Queries Written
| # | Query | Skill |
|---|---|---|
| Q1 | All customers by signup date | SELECT + ORDER BY |
| Q2 | Specific columns from Orders | Column selection |
| Q3 | Orders by payment method | WHERE clause |
| Q4 | Calculated total per order | Calculations + AS |
| Q5 | Orders sorted by date + cost | Multiple ORDER BY |
| Q6 | Orders count per customer | GROUP BY + COUNT |
| Q7 | Customer names with orders | JOIN 2 tables |
| Q8 | Top spending customers | JOIN 3 tables |
| Q9 | Order statistics | MIN/MAX/AVG/SUM |
| Q10 | Monthly sales summary | GROUP BY + DATE |
| Q11 | Products never ordered | Subquery |
| Q12 | High value orders | WHERE + filter |
| Q13 | Update product stock | UPDATE |
| Q14 | Create Sales Summary View | CREATE VIEW |
| Q15 | Query the View | SELECT from VIEW |

## 📈 Key Insights
- John Smith was the top spending customer at $1,799.98
- All 10 products were ordered at least once — no dead stock
- 3 out of 10 orders exceeded $1,000 — all from Electronics
- Total revenue across all orders: $8,098.82

- Primary & Foreign Keys

- SELECT with JOIN, GROUP BY, WHERE
- Subqueries
